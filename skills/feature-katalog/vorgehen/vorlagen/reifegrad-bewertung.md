# Reifegradbewertung

Je Bereich die höchste Stufe eintragen, deren Kriterien **alle** erfüllt sind (Stufen bauen aufeinander auf).

| Stufe | Kriterien |
|---|---|
| 1 Inventarisiert | Jede Schnittstellenart hat Erkennung oder eine begründete Lücke · `UNOWNED` = 0 · `OWNED_TWICE` = 0 |
| 2 Beschrieben | `UNASSIGNED` = 0 · jedes Feature mit fachlicher und technischer Ebene · Ausnahmen begründet |
| 3 Nachgewiesen | `check --reports` ohne Fehler · jedes Kriterium mit im letzten CI-Lauf bestandenem Nachweis |
| 4 Belastbar | Warnungen per Review geklärt · Mutationstests auf Kernkomponenten · Prüfbestand mit `owner` und sinkend |
| 5 Steuernd | neue Features Katalog-first · Release Notes/Planung aus dem Katalog · Vergleich gepflegt |
