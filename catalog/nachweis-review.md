# Nachweis-Review (Regel N7)

Je Nachweis: Kriterium → auslösende Aktion → Zusicherung (Zeilen im Test). Erzeugt mit
`python -m feature_catalog review`; die Zeilen sind eine Hilfe, keine Bewertung.

**Review-Stand:** Alle Nachweise beim Aufbau des Katalogs gegen den Testcode gelesen und bestätigt.
Wo die automatische Auswahl nicht die passende Zusicherung zeigt (große Tests wie
`test_full_lifecycle`), steht die zum Kriterium gehörige Zusicherung im selben Test weiter unten.

Bei jeder Änderung an `catalog/features/` die Tabelle neu erzeugen und die geänderten Zeilen im
Pull Request bestätigen.
